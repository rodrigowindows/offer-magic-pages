Blueprint Operacional: O Novo Fluxo 5 Passos

De processos fragmentados para uma linha de montagem comercial de alta performance.

1

Passo 1: Base de Imóveis (Inventário)

COMO É HOJE Fragmentado
O analista sobe o CSV em uma tela genérica, define um lote e os imóveis "caem" no sistema sem um destino claro.
URL: /admin/import
COMO SERÁ Focado em Lote
Tela dedicada para gestão de lotes. Cada importação gera um "card" de progresso.
  • Filtro por nome da Base (ex: PROBATE)
  • Visão de "Novos" vs "Já Existentes"
  • Botão direto: "Enviar para Análise"
2

Passo 2: Análise e Seleção (Triagem)

COMO É HOJE Lista Geral
Aprovação em massa sem obrigatoriedade de motivo. Dados de negação são perdidos.
URL: /admin (Aba Review)
COMO SERÁ Fila de Decisão
Foco em produtividade. Uma lista de cartões com fotos e dados críticos.
  • Botão Negar: Abre modal de motivos (Low equity, Bad area, etc)
  • Botão Aprovar: Move instantaneamente para o Passo 3
  • Rastreio: "Aprovado por [Nome] em [Data]"
3

Passo 3: Skip Trace (Enriquecimento de Contatos)

COMO É HOJE Fluxo Quebrado
Exporta aprovadas em uma tela. O retorno do fornecedor precisa ser subido em outra tela (/admin/import) que o analista de Skip Trace nem sempre acessa.
COMO SERÁ Workspace Unificado
TUDO EM UMA TELA:
  • Lado Esquerdo: Botão "Exportar Aprovadas do Dia" (Gera CSV para vendor)
  • Lado Direito: Dropzone "Upload Retorno Vendor" (Processa e cruza dados)
  • Centro: Tabela de contatos com Histórico Multifonte (Vendor A, Vendor B, Manual)
Diferencial PJ: Identificação automática de Officers/Sócios em empresas LLC/Inc.
4/5

Análise de Mercado e Oferta Final

COMO É HOJE Cálculo Manual
Comparativos são inseridos, mas o cálculo da oferta final muitas vezes é feito "por fora" ou em campos desconectados.
COMO SERÁ Calculadora Auditável
O sistema sugere a oferta baseada nos comparativos reais inseridos.
  • ARV (After Repair Value): Média dos comps
  • Fórmula: ARV - Reforma - Margem = Oferta Mínima
  • Aprovação Final: Botão para gerar PDF de Proposta
